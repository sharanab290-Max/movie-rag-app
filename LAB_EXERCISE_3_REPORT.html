CineGraph AI: Graph-Powered Movie Question Answering and Recommendation System Using Neo4j Knowledge Graph and LLM

Aim / Objective

This project builds an end-to-end Graph Retrieval-Augmented Generation (Graph RAG) Question Answering and Recommendation System for cinema intelligence. Given a user's free-text question about films, actors, directors, cast/crew, or recommendations, the system performs entity recognition, intent-based Cypher query routing, dynamic graph traversal over a Neo4j knowledge graph, and grounded natural language synthesis using a Large Language Model (LLM). The system is delivered as “CineGraph AI,” an interactive Streamlit web application backed by a modular Python graph NLP pipeline combining rule-based Cypher templates, a live Neo4j database driver with an embedded in-memory graph fallback engine, and grounded answer synthesis to ensure zero hallucination.

Expected Outcomes Addressed

  1. Load and utilize the Neo4j Movie Knowledge Graph. Populated with the canonical Neo4j Movies dataset comprising :Movie and :Person nodes connected via directed typed relationships (:ACTED_IN, :DIRECTED, :PRODUCED, :WROTE, :REVIEWED, :FOLLOWS), including node properties (release year, tagline, born year) and edge properties (character roles, review ratings).
  2. Convert natural language user questions into graph queries. Implemented through hybrid query translation: high-precision deterministic intent routing maps canonical queries to 11+ parameterized Cypher templates, while an LLM-assisted Text-to-Cypher generator with safety AST validation handles novel multi-condition questions.
  3. Retrieve relevant movie, actor, and connection subgraphs. The backend executes parameterized Cypher queries against the active graph database, retrieving exact multi-hop paths, cast rosters, collaboration frequencies, and reviewer ratings.
  4. Generate grounded natural-language answers. Context formatting synthesizes the retrieved graph records and supplies them to the LLM (Google Gemini / deterministic graph grounding engine) with strict grounding constraints, preventing trivia hallucination and explicitly explaining relationship connections.
  5. Support movie-related QA, collaborative recommendations, and network analytics. The system answers filmography questions, explores shortest path connections (Degrees of Separation / Bacon Numbers), and performs 2-hop co-star collaborative filtering recommendations through an interactive chat interface and visual graph network.

Dataset / Corpus Description

The application is backed by the canonical Neo4j Movies Knowledge Graph dataset, defined in data/movies_dataset.cql and data/seed_data.py. The corpus contains 171+ nodes and 253+ relationships:

  • Movie Nodes (:Movie): 28+ classic feature films (e.g., The Matrix, The Matrix Reloaded, The Matrix Revolutions, The Devil's Advocate, A Few Good Men, Top Gun, Jerry Maguire, Stand By Me, As Good as It Gets, What Dreams May Come, You've Got Mail, Sleepless in Seattle, When Harry Met Sally, That Thing You Do, The Replacements, Rescue Dawn, Unforgiven, Johnny Mnemonic, Cloud Atlas, The Da Vinci Code, V for Vendetta, Speed Racer, Apollo 13, Cast Away, The Green Mile) with attributes title (unique string), released (integer year), and tagline (promotional quote).
  • Person Nodes (:Person): 70+ actors, directors, screenwriters, and producers (e.g., Keanu Reeves, Tom Hanks, Tom Cruise, Jack Nicholson, Meg Ryan, Charlize Theron, Kevin Bacon, Lana Wachowski, Lilly Wachowski, Rob Reiner, Ron Howard, Nora Ephron) with attributes name (unique string) and born (birth year).
  • Graph Relationships:
    • [:ACTED_IN] — Edge connecting actor to movie with roles property list (e.g. ['Neo'], ['Maverick']).
    • [:DIRECTED] — Connects director to motion picture.
    • [:PRODUCED] — Connects creative/executive producer to film.
    • [:WROTE] — Screenplay author attribution.
    • [:REVIEWED] — User and critic reviews with integer rating (0–100) and text summary.
    • [:FOLLOWS] — Social graph connections between cinema enthusiasts.
  • Evaluation Question Corpus (test_queries): 8 test cases spanning actor filmographies, cast/crew lookups, 2-hop collaborative recommendations, shortest path traversals (Bacon Number), and top-rated review aggregations.

System Architecture / Pipeline Design

The system implements a transparent, cascading multi-stage Graph RAG architecture. Each user question passes through intent detection, graph retrieval, safety filtering, and grounded synthesis, displaying the active system mode and retrieved subgraph in the Streamlit UI.

  • Input: The user types a free-text question into the Streamlit chat box or clicks a 1-click suggestion chip.
  • Entity Recognition: RegEx pattern matching extracts recognized movie titles and person names from the question against known graph entities.
  • Intent Routing & Query Selection:
    • Template Match: If the question matches known patterns (filmography, director, cast, co-star, recommendation, path), it routes to a pre-validated, parameterized Cypher template.
    • Dynamic Text-to-Cypher: Novel or multi-constraint questions trigger a few-shot LLM translation prompt using the graph schema.
  • Cypher Validation & Safety Guardrails: Queries are checked against an AST filter prohibiting mutating operations (CREATE, DELETE, SET, DROP, MERGE) to enforce read-only execution.
  • Graph Traversal & Subgraph Retrieval: Cypher queries execute against the live Neo4j instance or embedded in-memory graph, returning matching nodes, properties, and relationship paths.
  • Grounded Answer Synthesis: Graph records are transformed into structured context. An LLM (or deterministic graph engine) generates a grounded natural language answer citing graph relationships.
  • Presentation: Streamlit displays the grounded answer, execution latency, system routing mode, an expandable Cypher trace panel, and an interactive vis.js visual subgraph.

Backend Implementation

6.1 Approach / Algorithm

The backend separates deterministic graph traversal from natural language synthesis to guarantee factual accuracy and zero hallucination.

  • Dual-Mode Graph Service: Neo4jGraphService attempts connectivity to a live Neo4j instance (bolt://localhost:7687 or AuraDB) with connection timeouts. If offline, it activates the InMemoryMovieGraph powered by NetworkX, ensuring 100% test reproducibility.
  • Database Seeding: seed_database() executes the canonical movies_dataset.cql script, creating uniqueness constraints on (:Person {name}) and (:Movie {title}).
  • Hybrid Intent Routing: match_template() identifies user intents (Filmography, Cast/Crew, Co-Actors, Collaborative Recommendations, Bacon Number, Reviews) using case-insensitive word-boundary matching.
  • Collaborative Recommendation Algorithm: Recommends films using a 2-hop co-star collaborative filtering traversal: Target Actor -> ACTED_IN -> Movie <- ACTED_IN <- Co-Star -> ACTED_IN -> Recommended Movie. Excludes films the target actor already starred in, and ranks candidates by co-star overlap score.
  • Shortest Path Traversal: Uses Cypher's shortestPath((p1)-[*]-(p2)) (or NetworkX BFS shortest path) to determine the degrees of separation between any two cinema individuals.
  • Strict Grounding Prompt: The synthesis prompt instructs the LLM to rely exclusively on retrieved graph nodes and relationships, preventing external hallucinations.

6.2 Key Code Snippets

Entity Extraction & Intent Routing (text2cypher.py):

def match_template(question: str) -> Optional[Dict[str, Any]]:
    q_lower = question.lower().strip()
    entities = extract_entities(question)
    movies = entities["movies"]
    persons = entities["persons"]

    # Collaborative Recommendation Intent
    if any(k in q_lower for k in ["recommend", "suggestion", "similar to", "fans of"]):
        if persons:
            return {
                "template_id": "RECOMMEND_BY_ACTOR",
                "params": {"actor": persons[0]},
                "matched_type": "deterministic",
                "explanation": f"Matched Collaborative Recommendation for fan of '{persons[0]}'"
            }
    
    # Degrees of Separation (Shortest Path) Intent
    if any(k in q_lower for k in ["how are", "connected", "path between", "bacon number"]):
        if len(persons) >= 2:
            return {
                "template_id": "SHORTEST_PATH",
                "params": {"person1": persons[0], "person2": persons[1]},
                "matched_type": "deterministic",
                "explanation": f"Matched Shortest Path between '{persons[0]}' and '{persons[1]}'"
            }

Cypher Query Template for Collaborative Recommendations (query_templates.py):

MATCH (target:Person)-[:ACTED_IN]->(m:Movie)<-[:ACTED_IN]-(coStar:Person)
WHERE toLower(target.name) = toLower($actor)
MATCH (coStar)-[:ACTED_IN]->(recMovie:Movie)
WHERE NOT (target)-[:ACTED_IN]->(recMovie)
RETURN recMovie.title AS movie, recMovie.released AS released, recMovie.tagline AS tagline,
       count(DISTINCT coStar) AS score, collect(DISTINCT coStar.name) AS via_co_actors
ORDER BY score DESC, recMovie.released DESC
LIMIT 5

Unified Graph Database Driver & Execution (graph_db.py):

def execute_cypher(self, cypher: str, params: Optional[Dict[str, Any]] = None) -> List[Dict[str, Any]]:
    params = params or {}
    if self.is_connected and self.driver:
        try:
            with self.driver.session(database=self.database) as session:
                result = session.run(cypher, params)
                return [record.data() for record in result]
        except Exception as e:
            return self.fallback_engine.query_freeform(cypher)
    else:
        return self.fallback_engine.query_freeform(cypher)

Frontend / UI Implementation

7.1 Framework

Streamlit was selected as the presentation layer to keep the Python Graph RAG pipeline and responsive user interface within a unified, high-performance architecture. The application utilizes a widescreen layout, custom dark cinema styling (#080b11 slate palette with glassmorphism), Google Fonts (Plus Jakarta Sans and Outfit), an interactive chat message stream, and embedded HTML5/JavaScript components for vis.js graph rendering.

7.2 UI Capabilities

  • Hero Header & Live Status Badge: Displays application title and real-time backend status (🟢 Connected: bolt://localhost:7687 or 🟡 Mode: Embedded Neo4j Movies Graph).
  • Real-time Metric Strip: Four cards summarizing Knowledge Graph Nodes (171), Relationships (253), Featured Movies (28+), and Cypher Templates (11+).
  • 1-Click Suggestion Discovery Chips: Quick-launch buttons executing popular cinema queries in a single click (Keanu Reeves filmography, Tom Cruise recommendations, Tom Hanks co-stars, Kevin Bacon shortest path).
  • Conversational Chat Stream: Implemented using st.chat_message and st.chat_input, maintaining dialogue history across user and assistant turns.
  • Dual-Pane Insight Layout: Left pane renders the grounded natural language answer, execution time badge, and collapsible Cypher query viewer; right pane renders the interactive vis.js subgraph.
  • Interactive Graph Visualizer (vis.js): ForceAtlas2-based physics-stabilized network rendering movies (amber boxes), persons (indigo dots), and relationship edges with zoom, pan, hover tooltips, and node drag.
  • Cypher Query Studio Tab: Interactive laboratory allowing users to select any of the 11 templates, customize parameters, view syntax-highlighted Cypher, and execute queries directly to inspect tabular records.
  • Knowledge Graph Catalog Tab: Searchable directory of all movies (titles, release years, taglines) and persons (birth years) with live substring search.
  • Sidebar Database & Seeding Manager: One-click database seeding (seed_neo4j.py), live Bolt URI/password configuration, and API key management.

Evaluation / Analysis

The system demonstrates successful end-to-end operation across intent detection, graph traversal, and grounded natural language synthesis. Testing was performed using canonical questions against the knowledge graph to assess retrieval accuracy, grounding fidelity, and execution latency.

Challenges Faced & Solutions

  • Ensuring Zero-Setup Reproducibility Across Environments: Running Neo4j Desktop or AuraDB requires account creation, local services, and network credentials. To ensure the lab exercise could be evaluated immediately without blocking on Neo4j startup, an automatic InMemoryMovieGraph engine (built with NetworkX) was implemented. It evaluates Cypher-like graph traversals with identical semantics, while allowing live Neo4j connections whenever available.
  • Eliminating LLM Trivia Hallucination: Standard LLMs frequently hallucinate actors or release years from external training data when asked movie questions. This was solved by applying a strict two-stage grounding pipeline: Cypher queries extract the ground truth subgraph, and the prompt instructs the LLM to refuse or omit any facts not present in the supplied graph context.
  • Windows Terminal Unicode Encoding Crashes: Outputting emoji characters (🍿, 🎬) to Windows PowerShell consoles running cp1252 encoding resulted in UnicodeEncodeError. This was resolved by sanitizing CLI print outputs with clean ASCII headers ([Recommendations], [Movie]) while preserving rich emojis in the Web UI.
  • Streamlit Path & Execution Resolution: Running Streamlit directly via PowerShell failed if Python's user scripts folder was not on system PATH. This was resolved by using python -m streamlit run app.py and setting root directory anchors.
  • Preventing Cypher Injection & Mutating Operations: Accepting free-form user questions for dynamic Cypher generation could risk data tampering. A regex AST sanitizer was implemented to reject any query containing mutating keywords (CREATE, DELETE, SET, DROP, MERGE, ALTER).

Conclusion

CineGraph AI demonstrates a complete, robust Graph RAG question-answering and recommendation workflow for cinema intelligence. The application resolves natural language questions through intent-based Cypher routing, executes multi-hop traversals over the Neo4j Movies Knowledge Graph (and embedded fallback engine), and generates grounded answers that eliminate hallucination. By combining structured graph traversals (collaborative recommendations, Bacon Numbers, cast metadata) with LLM natural language synthesis and interactive vis.js graph visualizations, the system provides an intuitive, user-friendly, and explainable AI assistant. Future extensions will incorporate vector embeddings for hybrid GraphRAG over unstructured review texts and live TMDB API ingestion.
